# 步骤 02 阶段提示规则表

本表列出当前生效的全部阶段饮食与生活提示规则，共 13 条，供你逐条审核。

## 一、说明

- 规则存放在一份独立的数据文件中，不写在程序代码里。要增加、删除或修改某条规则，只需要修改这份数据文件（步骤 02 后端目录下的经期模块内，文件名为 tips_rules.json），重新启动服务即可生效，不需要改动程序。数据文件里的每条规则都必须有编号、适用阶段、类别、严重程度、标题、内容、依据；编号不能重复，也不能缺项或多出未定义的项，否则读取规则时会报错，相关的阶段提示接口无法返回结果（自动化测试也会失败）。
- 用户查询某一天的阶段提示时，会得到“该阶段的规则”加上“适用阶段为所有阶段的通用规则”，按本表的先后顺序排列。阶段未知（例如数据不足、孕期或暂停）时，只返回通用规则。
- 类别分三种：营养学（有营养学或医学依据的饮食建议）、传统经验（传统饮食说法，缺少充分现代医学研究证据）、生活方式（睡眠、运动、就医提醒等）。
- 传统经验类单独标注，依据栏里一律写明“传统”字样，不作为医学结论，是否保留由你决定。
- 严重程度分两种：一般提示，普通的生活建议；需要注意，涉及就医提醒或不能用于避孕的重要说明。
- 所有阶段提示接口的返回内容末尾都附带固定说明：以上内容是一般性的生活方式建议，不构成医疗建议，不能用于避孕，也不能用于诊断；身体不适请及时就医。
- 最右一列“用户审核意见”：2026-09-30 由 Claude 经用户授权代为逐条审核并填写，4 条已修改、9 条保留，无删除。
