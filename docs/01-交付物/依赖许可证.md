# 步骤 01 依赖许可证

本文列出步骤 01 后端直接依赖的开源组件及其许可证，用于判断能否用于商业项目。

阅读约定：

- 只列直接依赖，即后端项目配置中明确声明的组件；它们自身再依赖的组件不逐一列出。
- 版本号与许可证取自 2026-09-30 在后端虚拟环境中实际安装的版本及其自带的许可证声明。
- “能否商用”基于“原样使用、不修改组件源码”的前提。本文不构成法律意见，正式商用前请以各组件官方许可证原文为准。

## 五、前端依赖（步骤 11）

步骤 11 新建了前端（frontend 目录，Vite 加 React 加 TypeScript 的单页应用）。与第一、二节一样只列直接依赖，即 frontend/package.json 里明确声明的组件；它们自身再依赖的组件不逐一列出。版本号取自 2026-10-13 的锁文件 frontend/pnpm-lock.yaml 里的解析版本（与 package.json 里写死的版本一致），许可证取自已安装包自带的 package.json 的许可证字段。项目只允许 MIT、Apache-2.0、BSD-2-Clause、BSD-3-Clause 四种许可证的新依赖，由前端测试读取已安装包的许可证字段逐个检查；同一个测试还确认没有安装任何动画库。界面组件只用 React Aria Components 提供行为与无障碍语义，样式全部自写；没有用 Ant Design Mobile，也没有拷贝 React Bits（MIT 加 Commons Clause 销售限制）的任何代码。

## 结论

步骤 01 的全部直接依赖都允许商用。唯一需要留意的是数据库驱动 psycopg 采用 LGPL-3.0：只要原样使用、不修改它的源码，就不会对本项目提出开源要求。步骤 06 新增的组件全部是 MIT、BSD-3-Clause 或 PSF 这类宽松许可证，同样允许商用。步骤 11 的前端依赖全部在 MIT、Apache-2.0 或 BSD 之内（实际只有 MIT 与 Apache-2.0），字体为 OFL-1.1，都允许商用。
