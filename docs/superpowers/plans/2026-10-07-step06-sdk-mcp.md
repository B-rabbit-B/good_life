# 步骤 06 SDK 与 MCP 封装 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把步骤 02 至 05 的领域能力封装成一份进程内 Python SDK（带版本、统一错误、读写分级授权、调用审计），再在其上包一层本地 stdio 的 MCP 服务，让任何通用 MCP 客户端都能用用户签发的授权令牌调用；医嘱确认与解除只在 SDK 里、且只认用户本人的登录令牌，MCP 不注册。满足 `docs/06-SDK与MCP封装.md` 的 7 条验收标准。

**Architecture:** 新增三个包。`app/agent_grants`：用户登录后签发"智能体授权"（只读或读写、有效期、可吊销，只存令牌哈希）。`app/sdk`：能力注册表（每项能力有名称、模块、授权级别、输入模型、输出类型、处理函数）、凭证认证、统一错误与结果信封、调用审计（独立表，不记参数与返回内容）；处理函数直接调用各模块现有的接口函数，保证 SDK 与 REST 的输入校验和输出完全一致。`app/mcp_server`：用 MCP 官方库的底层 Server，把注册表里非"需本人确认"的能力逐一暴露为工具，工具说明写清何时用、何时不用；不写任何业务规则。

**Tech Stack:** Python 3.12、FastAPI、SQLAlchemy 2、PostgreSQL 16、Alembic、pydantic v2、MCP 官方 Python 库 mcp 2.x（MIT 许可，底层 Server API、stdio 传输、`mcp.client.Client` 内存测试）、pytest（anyio 插件）。

**Spec:** `docs/06-SDK与MCP封装.md`（总览见 `docs/00-总览与串联.md`）。设计已在对话中由用户确认：进程内 SDK、用户签发的授权令牌、只做本地 stdio、医嘱确认与解除 SDK 有而 MCP 没有。

## 关键决策

| 决策 | 内容 | 理由 |
|---|---|---|
| SDK 形态 | 进程内 SDK，直连数据库，步骤 08 的智能体在后端内部直接使用 | 用户选定 |
| 用户与授权 | 用户登录后签发智能体授权令牌（只读或读写、有效期 1 至 365 天、可吊销），令牌形如 gl_ 加随机串，只存 SHA-256 哈希 | 用户选定；可单独分出只读、单独吊销 |
| MCP 传输 | 只做本地 stdio；令牌由环境变量 GOODLIFE_AGENT_TOKEN 提供，每次工具调用都重新认证，吊销立即生效 | 用户选定 |
| 医嘱确认与解除 | SDK 提供确认、修改、解除、作废、继续、撤回解除建议六项，级别 user_confirmed，只认用户登录令牌；MCP 不注册；模型只能用"提出解除建议" | 用户选定；与医嘱模块的 USER_ONLY_OPERATIONS 一一对应 |
| 处理函数复用接口函数 | SDK 处理函数直接调用各模块 router 里的接口函数（它们是普通函数，参数显式），输出再用对应的响应模型序列化 | REST 与 SDK 的校验、业务与输出只有一份实现，不会漂移；SDK 自己负责稳定的能力名、参数模型、错误与版本 |
| 数据不足 | 不算错误：成功结果附带 notices（类别 insufficient_data），例如经期数据不足、档案不全无法估算需求、没有体重无法估算消耗 | 这些情形下仍有可用数据，智能体应如实告知并引导补充 |
| 审计存储 | 独立表 sdk_call_audits；未认证的调用 user_id 为空；写审计用独立会话，业务失败回滚不影响审计 | 每次调用都能查到 |
| 工具命名 | 能力名 module.action，MCP 工具名把点换成下划线，例如 nutrition_log_meal | MCP 工具名通用写法 |

  - 接口（前缀 `/api/agent-grants`，依赖 `require_disclaimer_user`）：POST ``（201，返回含 token 的一次性结果）、GET ``（列表，不含 token，含 status）、DELETE `/{grant_id}`（204）
  - 错误码：`too_many_grants`(409，有效授权已达 20 个)、`not_found`(404)
- 请求体：`{"name": 1 至 50 字（去首尾空白）, "access": "read" | "read_write", "expires_in_days": 1 至 365，默认 90}`，extra="forbid"。

  - `app.sdk.client`：`SDK_VERSION = "1.0"`；`SdkResult(data: Any, notices: tuple[Notice, ...])`，`to_dict() -> {"ok": True, "sdk_version", "data", "notices": [{"kind", "message"}]}`；`error_envelope(err: SdkError) -> {"ok": False, "sdk_version", "error": err.to_dict()}`；`class GoodLife(session_factory=None, today: Callable[[], date] = date.today, registry=None)`，方法 `call(credential, capability: str, params: dict | None = None, *, client_name: str = "sdk") -> SdkResult`（失败抛 SdkError）、`capabilities() -> list[Capability]`

  - ORM `SdkCallAudit`（表 sdk_call_audits）：id、user_id（可空，外键 users 级联删除，索引）、grant_id（可空，外键 agent_grants，删除时置空）、credential_kind（String(16)：agent_grant、user_session、none）、client_name（String(64)）、capability（String(64)）、outcome（String(8)：ok、error）、error_code（String(64)，可空）、duration_ms（Integer）、created_at

  - `app.sdk.capabilities.profile.CAPABILITIES`：只有 `profile.get_capabilities`（read，模块 profile，NoParams，输出 `dict[str, bool]`）
  - `app.sdk.capabilities.ALL`：本任务只含 profile；任务 3 追加其余模块

`GoodLife.call` 的固定顺序：
1. 记开始时间；用 `session_factory()`（默认 `app.db.get_sessionmaker()`）开一个会话。
2. `authenticate`；失败直接进入第 8 步。
3. 查能力；不存在抛 SdkError(invalid_input, `unknown_capability`，hint 提示先列出可用能力)。
4. 级别：`user_confirmed` 能力要求 `caller.user_confirmed`（只有 UserAccessToken 为真），否则 SdkError(needs_user_confirmation, `user_confirmation_required`, hint "这一步只能由用户本人在应用里操作；如需解除医嘱，可以调用 medical.propose_resolution 提出解除建议")；`write` 能力要求 `caller.can_write`（只读授权为假），否则 SdkError(forbidden, `write_not_granted`, hint "当前授权只允许读取；需要写入时请让用户创建读写授权")。
5. 准入：先 `require_disclaimer_user`；模块不是 profile 时再调用对应模块的 `require_*_user`（AppError 经 `from_app_error` 转换）。
6. 参数：`params or {}` 用 `input_model.model_validate` 校验（ValidationError 转换）。
7. 执行 `handler(CallContext(db, user, today()), parsed)`；结果用 `TypeAdapter(output_type)` 以 `from_attributes=True` 校验后 `dump_python(mode="json")`；`notices` 函数作用在序列化后的数据上。
8. 不论成败，用 `audit.record_call` 记一行（未认证时 user_id、grant_id 为空，credential_kind 为 none；capability 取请求的名称截断到 64 字；client_name 只保留可打印字符并截断到 64 字，空则为 "sdk"）；AppError、ValidationError 转成 SdkError 抛出；其它异常记日志（`logger.exception`，不含参数）后抛 SdkError(internal, `internal_error`)；成功返回 SdkResult。
9. 会话在 finally 关闭；出错时先 rollback。

`from_app_error` 的映射：401 → unauthenticated；403 且 code 以 `_not_available` 结尾 → module_unavailable；403 `disclaimer_not_accepted` → needs_user_confirmation（hint "请让用户先在应用里阅读并确认免责声明"）；其它 403 → forbidden；404 → not_found；409 → conflict；400、413、415、422 → invalid_input；其它 → internal。code 与 message 原样保留，hint 取 `DEFAULT_HINTS[kind]`（每个类别一句面向智能体的下一步建议，中文）。

```python
import json
import os
import sys
from datetime import date
from pathlib import Path

import pytest
from mcp.client import Client

from app.mcp_server.server import build_server, exposed_capabilities, tool_name
from app.mcp_server.usage import TOOL_USAGE
from app.sdk import AgentGrantToken, GoodLife
from app.sdk.registry import REGISTRY
from tests.helpers import ready_user

TODAY = date(2026, 10, 7)
BACKEND = Path(__file__).resolve().parents[1]


def _token(client, headers, access="read_write"):
    return client.post("/api/agent-grants", json={"name": "mcp", "access": access}, headers=headers).json()["token"]


def _server(token):
    return build_server(GoodLife(today=lambda: TODAY), lambda: AgentGrantToken(token) if token else None, "pytest")


def test_usage_covers_exactly_the_exposed_capabilities():
    exposed = {cap.name for cap in exposed_capabilities(REGISTRY)}
    assert len(exposed) == 26 and set(TOOL_USAGE) == exposed
    assert not any(REGISTRY[name].level == "user_confirmed" for name in exposed)


@pytest.mark.anyio
async def test_tools_listed_without_confirmation_tools():
    async with Client(_server(None)) as mcp:
        tools = (await mcp.list_tools()).tools
    names = {tool.name for tool in tools}
    assert len(names) == 26 and "medical_propose_resolution" in names
    assert not {"medical_confirm_item", "medical_resolve_item", "medical_void_item"} & names
    for tool in tools:
        assert "什么时候用" in tool.description and "什么时候不要用" in tool.description
        assert "user_id" not in tool.input_schema.get("properties", {})


@pytest.mark.anyio
async def test_call_without_token_is_a_structured_error():
    async with Client(_server(None)) as mcp:
        result = await mcp.call_tool("profile_get_capabilities", {})
    assert result.is_error
    assert result.structured_content["error"]["kind"] == "unauthenticated"
    assert json.loads(result.content[0].text) == result.structured_content


@pytest.mark.anyio
async def test_write_and_read_through_mcp(client):
    headers = ready_user(client, "alice", {"gender": "female"})
    async with Client(_server(_token(client, headers))) as mcp:
        ok = await mcp.call_tool("cycle_record_period", {"start_date": "2026-09-10", "end_date": "2026-09-14"})
        confirm = await mcp.call_tool("medical_confirm_item", {"item_id": "00000000-0000-0000-0000-000000000000"})
        bad = await mcp.call_tool("nutrition_log_meal", {"meal_type": "lunch"})
    assert not ok.is_error and ok.structured_content["data"]["start_date"] == "2026-09-10"
    assert confirm.is_error and confirm.structured_content["error"]["code"] == "unknown_capability"
    assert bad.is_error and bad.structured_content["error"]["kind"] == "invalid_input"


@pytest.mark.anyio
async def test_read_only_grant_cannot_write(client):
    headers = ready_user(client, "alice", {"gender": "female"})
    async with Client(_server(_token(client, headers, "read"))) as mcp:
        result = await mcp.call_tool("cycle_record_period", {"start_date": "2026-09-10"})
    assert result.is_error and result.structured_content["error"]["code"] == "write_not_granted"


@pytest.mark.anyio
async def test_stdio_smoke(client):
    from mcp.client.stdio import StdioServerParameters, stdio_client
    from mcp import ClientSession

    token = _token(client, ready_user(client, "alice"), "read")
    params = StdioServerParameters(command=sys.executable, args=["-m", "app.mcp_server"], cwd=str(BACKEND),
                                   env={**os.environ, "GOODLIFE_AGENT_TOKEN": token, "GOODLIFE_CLIENT_NAME": "stdio"})
    async with stdio_client(params) as (read, write), ClientSession(read, write) as session:
        await session.initialize()
        result = await session.call_tool("profile_get_capabilities", {})
    assert not result.is_error and result.structured_content["data"]["nutrition"] is True
```
