# 开源使用说明

本文汇总项目用到的全部开源组件、数据与字体，回答三个问题：用了什么、什么许可证、能不能商用。逐步骤的原始记录在《依赖许可证》（步骤 01 的交付物目录）与各步骤的营养库授权清单、选型说明里，本文以锁文件里的实际版本重新核对并合并。

阅读约定：

- 只列直接依赖，即后端项目配置与前端包配置里明确声明的组件；它们自身再依赖的组件不逐一列出（随官方 MCP 库一起装入的组件见《依赖许可证》第四节）。
- 版本取锁文件：后端取 uv 的锁文件，前端取包管理器的锁文件。许可证取自已安装包自带的元数据，与《依赖许可证》逐项一致。
- “能否商用”基于“原样使用、不修改组件源码”的前提，不构成法律意见，正式商用前请以各组件官方许可证原文为准。
- 项目没有拷贝任何开源项目的代码或数据；只参考不复用的项目与调研过但未使用的项目分别列在后面两节。
- 仓库保持私有，营养库里有仅供个人学习的数据，对外公开或商用之前必须按本文最后一节处理。

## 结论与商用前必须处理的事项

- 全部直接依赖的许可证都在 MIT、BSD、Apache-2.0、PSF 这类宽松许可证之内，只有数据库驱动 psycopg 是 LGPL-3.0：原样使用、不修改驱动源码，就不会对本项目提出开源要求。字体为 OFL-1.1，允许商用。
- 唯一阻碍商用与公开的是营养库：成分表整理数据与由它计算的菜品仅供个人学习，手动估算的 21 个未核对。商用或公开仓库之前，必须联系仓库作者与原书版权方取得书面授权，或删除成分表整理数据与由它计算的菜品，改用自建或有明确授权的数据替换（程序只依赖食物的字段结构，替换数据文件即可，不需要改规则）。
- 这也是仓库保持私有的原因之一，详见《取舍记录》。
